# Mapa de cobertura dos testes locais

**Baseline de arquivos:** checkout `1422b5f`, 10/11/2026 · **Estado:** inventário preliminar por nome; leitura e execução dos testes ainda necessárias · **Meta:** [testes locais](META-TESTES-LOCAIS.md)

Este mapa cruza áreas da interface `src/modules/`, rotas `src/app/api/v1/` e arquivos de teste pelo nome e pela organização existente. É uma triagem para planejar trabalho, não declaração de cobertura. `Candidato` significa que o assunto parece relacionado pelo nome; só vira `Verificado` quando o caso e seu resultado observado forem lidos e registrados. Teste de função de domínio não prova que a tela e a API funcionam juntas.
